# Pong Wars

[![C](https://img.shields.io/badge/C-00599C?style=flat&logo=c&logoColor=white)](https://en.cppreference.com/w/c/language.html)

A simple C program that displays two bouncing circles fighting for each other's territory.

I initially made this program to learn about how to make pop-up windows using C.
